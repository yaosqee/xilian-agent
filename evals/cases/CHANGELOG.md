# 评测集版本与冻结规则

## 当前版本

- **v1（2026-11-04 冻结）**：`agent_loop_v2.jsonl`，40 条，train 20 / holdout 20，
  六类：weather 8 / time 6 / memory 6 / search 6 / no_tool 8 / multi_step 6。
- 指纹：每次评测报告里都有 `cases_sha256`，用例一改就能看出来。

## 规则（重要）

1. **holdout 一旦看过结果，不得修改**。改了就只能是"新版本"，并把旧版本留在本目录（`agent_loop_v2.v0.jsonl` 之类）。
2. 发现用例本身无效（例如可被单一工具满足、期望值写错）时：
   - 不要原地改 holdout；
   - 在用例里加 `"valid": false` 并移出计分，或升版本另建文件；
   - 在本文件记录原因和日期。
3. 任何"看了结果再调提示词"的改动，都要在报告里标注，并同时给出 **改动前** 与 **改动后** 两组数字。
4. 冻结后定期跑 `--mode all`，train / holdout 分开报；holdout 才是对外可信的数字。
